# Truyện Kiều — Nguyên văn & Giải nghĩa

A reader for Nguyễn Du's *Truyện Kiều*, with the original text, line-by-line
meanings, and reading notes (narrative and cultural layers).

## Status: partially restored

The original repository was lost when its GitHub account was suspended. This
repo has the reader's add-on layers, but **the core poem data is missing**
(the text, meanings, Hán-Việt and vocabulary files), so the page won't work
fully yet.

- `index.html`: the last confirmed page, plus the cultural-layer add-on
- `js/`, `css/`: reader insights, narrative layers, cultural layers, layout
- `tests/`: data tests (run with `node --test`)
- `MISSING_EXACT_FILES.md`: the files that still need to be restored
- `RECOVERY_STATUS.md`, `README_RECOVERY.md`, `APPLY.md`, `SNAPSHOT.txt`:
  recovery notes
